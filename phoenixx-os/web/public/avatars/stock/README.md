# Stock avatar photos

People who have not uploaded a photo of their own get one of these, picked
from their name (the same person always gets the same photo).

1. Put the image files in this folder (JPG, PNG, WebP or AVIF; square, at
   least 256 x 256, faces centred).
2. List them in `manifest.json`, for example:

   ```json
   { "photos": ["01.jpg", "02.jpg", "03.jpg"] }
   ```

Only use photos you are licensed to use this way - ideally AI-generated
faces of people who do not exist, under a licence that allows commercial use.
With no photos listed, avatars show soft initials.
